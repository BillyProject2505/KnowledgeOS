# Registries

## Purpose

Stores the centralized metadata registries for the Knowledge Operating System (KOS).

These registries manage metadata about documents, knowledge objects, versions, relationships, and other system-level information.

Registries are considered system services and act as the authoritative metadata layer of the repository.

---

## Initial Registries

- Knowledge Object Registry
- Document Registry
- Version Registry
- Relationship Registry

Additional registries may be introduced as the system evolves.

---

## Rules

- Registries do not contain knowledge content.
- Registries store metadata only.
- Every specification may reference these registries.
- Registry identifiers must be unique across the repository.
