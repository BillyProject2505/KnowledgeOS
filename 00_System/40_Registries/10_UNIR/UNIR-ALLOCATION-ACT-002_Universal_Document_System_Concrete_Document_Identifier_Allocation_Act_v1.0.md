## 1. Allocation Decision

The UNIR Registry Authority hereby allocates:

**`DIUA-DIC-000004`**

The allocation operates within the canonical Universal Naming and Identification architecture established by UNIS.

The applicable Document Identifier Grammar is:

```text
<Namespace>-DIC-<6DigitSequence>
```

The applicable sequence allocation follows the Universal Sequence Model.

## 4. Allocation Context

The currently established concrete Document Identifier allocation sequence is:

```text
DIUA-DIC-000001 → Universal Naming and Identification Standard
DIUA-DIC-000002 → Universal Architecture
DIUA-DIC-000003 → Universal Governance
DIUA-DIC-000004 → Universal Document System
```

`DIUA-DIC-000001`, `DIUA-DIC-000002`, and `DIUA-DIC-000003` are prior concrete Document Identifier allocations and remain distinct from the present allocation.

## 5. Identity Boundary

This allocation establishes the concrete document identity of the Universal Document System.

It does not create:

- a new UNIR Registry Object;
- a new DIC definition;
- a new Document Identifier Grammar;
- a new DIUA namespace;
- a new UNIR Core specification.

The following remain distinct:

```text
Concrete Document Identifier
        ≠
UNIR Registry Object ID
        ≠
Allocation Record
        ≠
Allocation Event
        ≠
Document Representation
```

## 6. Authority Boundary

UNIS remains the normative authority for Universal Naming and Identification semantics.

UNIR provides the operational registry and allocation machinery within that normative architecture.

This allocation act does not transfer normative naming or identification authority from UNIS to the allocation record or target document.

## 7. Temporal Effect

**Allocation Effective State:** ACTIVE upon recording of this act.

The allocated identifier shall remain persistently associated with the Universal Document System unless a subsequent authorized governance act supersedes, withdraws, or otherwise changes the allocation.

Identifier reuse for a different governed document is not authorized by this act.

## 8. Registry Traceability

This allocation act shall be represented in the applicable UNIR registration-record traceability layer and reflected in the current UNIR registry state through the applicable controlled materialization process.

The allocation act is the authoritative allocation decision for `DIUA-DIC-000004` within its defined scope.

## 9. Non-Implication

This act does not by itself:

- establish publication authorization for the Universal Document System;
- alter the substantive semantics of UDS;
- modify `UNIS-CORE-001 v1.7`;
- reopen or revise the target document;
- establish a new Universal-level authority beyond the allocation granted here.
