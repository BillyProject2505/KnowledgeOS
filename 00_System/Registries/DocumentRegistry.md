# Document Registry

## Purpose

The Document Registry is the authoritative catalog of all official documents maintained by the Knowledge Operating System.

Unlike the Knowledge Object Registry, this registry focuses on documents as publishable artifacts.

---

## Scope

Examples include:

- Specifications
- Production Bibles
- Standards
- Guidelines
- Policies
- Manuals

---

## Document Identifier

```
DOC-0001
DOC-0002
DOC-0003
```

Document identifiers are unique and permanent.

---

## Registry Fields

| Field | Description |
|---------|-------------|
| Document ID | Official document identifier |
| Title | Official title |
| Category | Specification / Standard / Policy / Guide |
| Owner | Responsible authority |
| Status | Draft / Review / Canonical / Deprecated |
| Current Version | Latest version |

---

## Rules

- Every official document must appear here.
- Only one active version may be Canonical.
- Deprecated documents remain for historical reference.

---
