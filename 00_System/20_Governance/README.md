## Governance Rules

- Governance documents define applicable governance rules within their declared scope.
- Universal Governance is the canonical Universal-level governance authority for the Universal system.
- Repository governance documents govern repository implementation and operational concerns within their declared scope.
- Governance follows the applicable Universal Architecture and shall not silently redefine architectural authority.
- Repository presence, publication, or implementation does not independently create canonical authority.
- Canonical documents shall be identified by their stable Document ID and controlled canonical state rather than filename alone.
