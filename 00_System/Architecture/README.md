# Architecture

## Purpose

The Architecture layer defines the conceptual design of the Knowledge Operating System (KOS).

It explains **what KOS is**, **how it is structured**, and **why architectural decisions were made**.

## Contents

- KOS Architecture Specification (KOS-AS)
- Conceptual Models
- Architecture Diagrams
- Architecture Decision Records (ADR)

## Scope

Architecture documents define the system itself.

They do not contain reusable operational Knowledge Objects such as Frameworks, Bibles, Standards, or Prompts.

Those belong in `01_Knowledge`.
