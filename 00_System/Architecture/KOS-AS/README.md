# Knowledge Operating System Architecture Specification (KOS-AS)

## Purpose

The Knowledge Operating System Architecture Specification (KOS-AS) defines the conceptual architecture of the Knowledge Operating System.

It serves as the highest-level architectural reference for how knowledge is organized, managed, governed, and integrated across repositories, projects, and AI workflows.

---

## Scope

KOS-AS describes the architecture of the system rather than its implementation.

Implementation details are documented separately in the Physical Repository Specification (PRS) and Implementation Plan (IP).

- Part 02 — Core Concepts
- Part 03 — Knowledge Object Model
- Part 04 — Repository Architecture
