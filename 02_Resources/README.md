# 02_Resources

## Purpose

This directory contains supporting resources and reference materials used by KnowledgeOS and its projects.

## Scope

Resources may include reference material, supporting evidence, external-source extracts, media, templates, or other non-authoritative assets used to support research, production, validation, or implementation.

A resource does not become canonical solely because it is stored here.

## Authority Boundary

Resource authority is determined by the resource's own source, provenance, declared status, and applicable governing artifact.

Repository placement is contextual and does not independently establish normative authority.

### Local Contents

Organize resources according to their project or functional use while preserving provenance and source references.

## Maintenance Rules

- Preserve source provenance and attribution where applicable.
- Distinguish supporting evidence from canonical knowledge.
- Do not treat resource files as normative replacements for canonical documents.
- Preserve stable references where recovery or verification may be required.
- Do not create duplicate substantive authority in this README.
- Keep this README focused on navigation, scope, and resource boundaries.
