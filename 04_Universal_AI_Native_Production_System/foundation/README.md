# Foundation

## Purpose

This directory contains the foundational conceptual reference for the new AI-Native Production System trajectory.

## Primary Document

`UAICP-FC-001-foundational-concept-and-north-star_v1.0.md`

This document defines the project's conceptual North Star, intended end-state, lessons learned, and methodological direction.

## Boundary

Foundation documents answer **what the project is intended to become and why**.

They do not define the final architecture, governance model, registry model, implementation, or operational procedures.

The use of the word **Universal** in later core documents denotes an architectural or knowledge scope that has been established through the research and construction process; it is not a naming requirement for every root-level methodology artifact.

## Current Research State

Steps 1–10 are currently published in the repository.

After Step 10, the workflow becomes outcome-driven. Step 10 produces an **Architecture Decision Basis**, not an automatically approved architecture or a predetermined Step 11.

The architecture-decision transition is governed by `UAICP-ADM-001`, which is a root-level transition mechanism rather than a numbered discovery step. Its current file is:

`../governance/UAICP-ADM-001-architecture-decision-model-v1.0.md`

The transition is:

```text
Architecture Discovery
        ↓
Architecture Decision Basis
        ↓
Architecture Decision Model
        ↓
Architecture Decision
```

`UAICP-ADM-001` does not define the architecture itself, create decision authority, or establish final Universal Governance.

## Reading Rule

AI and human readers should treat foundation documents as conceptual anchors and resolve methodological, normative, architectural, governance, and implementation rules from the appropriate later authoritative artifacts.

Foundation content must not be interpreted as establishing final architecture or final Universal-layer scope by itself.
