# Foundation

## Purpose

This directory contains the foundational conceptual references for the new Universal AI-Native Production System trajectory.

## Primary Document

`UAICP-FC-001-foundational-concept-and-north-star.md`

This document defines the project's conceptual North Star, intended end-state, lessons learned, and methodological direction.

## Boundary

Foundation documents answer **what the project is intended to become and why**.

They do not define the final architecture, governance model, registry model, implementation, or operational procedures.

## Reading Rule

AI and human readers should treat foundation documents as conceptual anchors and resolve normative rules from the appropriate later authoritative artifacts.
