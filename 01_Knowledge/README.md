# 01_Knowledge

## Purpose

Stores canonical Knowledge Objects and reusable knowledge assets managed by KnowledgeOS.

---

## Scope

Knowledge that is intended to be reused, referenced, interpreted, or consumed across projects.

Repository placement is determined by the artifact's canonical function and authority. Knowledge Object Type does not by itself determine repository location.

## System Boundary

The following are System artifacts and are not canonical Knowledge categories:

- Architecture
- Governance
- Standards
- Registries
- Specifications
- Releases

System artifacts belong under `00_System` according to their applicable canonical layer.

## Canonical Boundary Principle

`01_Knowledge` contains knowledge-bearing artifacts. It does not acquire System authority merely because a Knowledge Object may describe standards, systems, classifications, or other governed concepts.
