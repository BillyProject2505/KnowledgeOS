# Purpose

The Brand Presenter defines the permanent canonical identity of the official human representative of the Coz We Care brand.

It serves as the authoritative human identity asset for all visual communication requiring a presenter, spokesperson, educator, counselor, or narrative character representing the organization.

This Canonical Asset is composed of two synchronized representations:

- the Specification File, which defines the canonical biological, anatomical, facial, physical, and rendering characteristics;
- the Canonical Reference Sheet, which provides the authoritative visual interpretation of those characteristics.

Together, these representations constitute the Single Source of Truth for the Brand Presenter.
