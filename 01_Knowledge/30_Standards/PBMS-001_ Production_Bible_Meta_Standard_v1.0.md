# PBMS-001 — Production Bible Meta Standard

Status: LOCK
Version: 1.0
Type: Meta Standard
Scope: Entire Production Bible

---

# Purpose

Production Bible Meta Standard (PBMS) defines the canonical rules for authoring, maintaining, and evolving the Production Bible.

PBMS governs the documentation itself.

PBMS does not govern production operations.

---

# Responsibilities

PBMS SHALL define:

- Document Structure
- Heading Hierarchy
- Numbering Rules
- Section Naming
- LOCK Format
- Versioning Rules
- Cross Reference Rules
- Documentation Templates
- Editorial Writing Rules
- Example Format
- Table Format

PBMS SHALL NOT define:

- Brand Standards
- Layout Standards
- Design Standards
- Content Standards
- Workflow Standards
- Quality Standards

---

# Canonical Principles

## PBMS-CP-001

Title:
Meta Before Content

Statement:
Documentation rules SHALL exist before documentation content.

---

## PBMS-CP-002

Title:
Consistency Over Preference

Statement:
Consistency SHALL always take precedence over author preference.

---

## PBMS-CP-003

Title:
Single Documentation Standard

Statement:
Every Production Bible document SHALL follow one documentation standard.

---

## PBMS-CP-004

Title:
Repository Agnostic

Statement:
PBMS SHALL remain independent from repository structure.

---

## PBMS-CP-005

Title:
Traceable Evolution

Statement:
Every document change SHALL be traceable.
