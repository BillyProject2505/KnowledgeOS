# Overview

AI-First Documentation Standard (AIFDS) adalah standar dokumentasi yang dirancang untuk menghasilkan dokumentasi yang mudah dipahami, dipelihara, dan digunakan oleh manusia maupun sistem AI.

AIFDS menjadi **Single Source of Truth (SSOT)** untuk seluruh aturan dokumentasi dalam repository.

Dokumen ini merupakan **entry point** menuju seluruh spesifikasi AIFDS.

---

# Purpose

README bertujuan untuk:

- memperkenalkan AIFDS;
- menjelaskan ruang lingkup AIFDS;
- menyediakan navigasi menuju seluruh spesifikasi;
- membantu pembaca memahami struktur dokumentasi.

README bukan merupakan dokumen normatif dan tidak mendefinisikan aturan teknis.

---

# Guiding Principles

AIFDS dibangun berdasarkan prinsip-prinsip berikut:

- AI First
- Human Readable
- Single Source of Truth
- Repository Agnostic
- One File, One Responsibility
- Stable Identifier
- Explicit Structure
- Architecture Before Implementation

---

# Architecture Overview

AIFDS terdiri atas sekumpulan spesifikasi modular yang secara bersama-sama membentuk satu standar dokumentasi.

```
AIFDS
│
├── Overview
├── Documentation Classification
├── Information Model
├── Document Structure
├── Writing Rules
├── Document Templates
├── Cross Reference
├── Versioning
├── Governance
├── Registry
└── GitHub Implementation
```
