# Principles

## Purpose

Folder **Principles** menyimpan prinsip-prinsip fundamental yang menjadi landasan seluruh KnowledgeOS.

Principle mendefinisikan nilai, filosofi, dan aturan dasar yang harus diikuti oleh seluruh framework, standard, bible, registry, template, prompt, maupun dokumen lainnya.

Prinsip bersifat:

- Fundamental
- Jangka panjang
- Stabil
- Berlaku lintas proyek
- Menjadi dasar pengambilan keputusan

---

# Scope

Folder ini digunakan untuk menyimpan dokumen seperti:

- Knowledge Principles
- Design Principles
- Architecture Principles
- Repository Principles
- Writing Principles
- Governance Principles
- AI Collaboration Principles

---

# Relationship

Hierarchy dalam KnowledgeOS adalah sebagai berikut:

```
Principles
    ↓
Frameworks
    ↓
Standards
    ↓
Bibles
    ↓
Registries
    ↓
Templates
    ↓
Prompts
```

Seluruh dokumen pada level di bawahnya harus konsisten dengan prinsip-prinsip yang ditetapkan di folder ini.

---

# Document Rules

Dokumen pada folder ini harus:

- Bersifat konseptual.
- Tidak menjelaskan prosedur teknis.
- Tidak bergantung pada proyek tertentu.
- Dapat digunakan kembali pada seluruh repository.

---

# Naming Standard

Seluruh dokumen mengikuti DNS-001.

Contoh:

```

RP-001_Repository_Principles_v1.0.md

GP-001_Governance_Principles_v1.0.md
```
