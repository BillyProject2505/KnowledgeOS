## Usage Rules

- Use only assets marked `CANONICAL` for production work.
- Do not recreate or replace the official logo using AI-generated output.
- Do not alter the logo's proportions, geometry, or identity.
- Do not substitute exploratory logo concepts or mockups for the canonical assets.
- Use the primary logo as the default brand mark unless the transparent version is specifically required by the layout.
- Canva is the finalization layer for logo placement, sizing, alignment, spacing, and treatment.

## Reference / Exploratory Assets

Logo concepts, concept boards, profile explorations, and other generated variants from the production conversation are considered `REFERENCE` unless explicitly approved as canonical in the project decision register.

They should not be uploaded to this directory merely for archival purposes.

## Version / Authority Note

The project decision register records the approved BAKU Edit Tugas logo as the official brand mark. The canonical binary assets in this directory are the approved files currently used for production.

If a future logo is explicitly approved as a replacement, update the decision register and this README before treating the new asset as canonical.
