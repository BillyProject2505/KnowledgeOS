# BAKU Edit Tugas — Instagram Content

Directory ini adalah pusat konten Instagram BAKU Edit Tugas.

## Scope

Mencakup perencanaan, copy, production brief, dan content package untuk Instagram.

## Current Content Areas

- Story Highlight FAQ
- Feed posters
- Hero Service series
- Caption dan supporting copy untuk publikasi

## Workflow

**Content Brief → Copy QC → Visual Production → Canva Finalization → Final QC → Publish → Update Tracker**

## Rules

- Gunakan service catalog yang berlaku.
- Jangan membuat klaim yang tidak terverifikasi.
- Pertahankan identitas visual BAKU.
- Untuk poster, gunakan standard teknis dan visual canonical.
- Status publikasi harus dicatat di tracker seri jika konten termasuk Hero Service.
