# BAKU Edit Tugas — Instagram Story Production Standard

**Version:** 1.2  
**Date:** 2026-09-08  
**Status:** APPROVED

## Purpose

Dokumen ini adalah standar reusable untuk produksi Instagram Story BAKU Edit Tugas. Dokumen ini mengatur system produksi visual dan QC, bukan strategi konten atau copy untuk workstream tertentu.

Content-specific requirements tetap disimpan pada folder/content document masing-masing.

## Scope

Berlaku untuk:

- Instagram Story statik;
- Story Highlight;
- Story series yang menggunakan identitas visual BAKU Edit Tugas.

Tidak mengatur:

- Feed/poster;
- Reels/video;
- caption strategy;
- hashtag strategy;
- platform ranking claims;
- content strategy spesifik suatu campaign.

## 1. Canvas & Format

- Format: static Instagram Story.
- Aspect ratio: 9:16.
- Target size: 1080 × 1920 px.
- Output: static image.
- Video dan animation tidak digunakan kecuali ditetapkan secara eksplisit oleh brief baru.

## 2. Brand Asset Rules

Gunakan hanya canonical brand assets yang tersimpan di:

`02_Assets/Brand/`

Canonical logo:

- `BAKU_Edit_Tugas_logo-primary.png`
- `BAKU_Edit_Tugas_logo-transparent.png`

Rules:

- Jangan menggambar ulang logo.
- Jangan mengganti logo dengan hasil AI generation.
- Jangan stretch, distort, atau mengubah geometry/logo identity.
- Untuk series yang sudah memiliki baseline approved, posisi dan relative scale logo mengikuti baseline tersebut.
- Canva adalah finalization layer untuk logo placement, sizing, alignment, dan spacing.
- Jika visual reference menampilkan logo hasil AI, perlakukan bentuk/posisinya hanya sebagai referensi komposisi; logo final wajib diganti dengan canonical BAKU logo di Canva.

## 3. Canonical Visual Baseline

Visual baseline canonical BAKU Instagram Story sekarang menggunakan **flat editorial service-poster composition** yang telah ditetapkan melalui approved reference set dan diperkuat oleh desain referensi LAYANAN terbaru.

Baseline ini harus menghasilkan tampilan yang:

- warm, friendly, dan professional;
- jelas terbaca dalam sekali lihat;
- terasa seperti satu sistem brand, bukan kumpulan template yang berbeda;
- menggunakan ilustrasi sebagai visual utama, bukan sekadar decorative filler;
- menjaga hierarchy yang kuat dari logo → hook → answer → supporting copy → illustration → service/footer cue.

### 3.1 Fixed Visual Characteristics

Karakteristik berikut diperlakukan sebagai system-level baseline:

- warm cream/off-white background;
- deep navy primary;
- warm gold/yellow accent;
- dark navy/charcoal text;
- canonical BAKU logo dengan treatment konsisten;
- large bold uppercase question/hook sebagai first reading point;
- prominent rounded dark-navy answer box dengan gold answer text;
- thin gold divider/accent lines untuk mengikat hierarchy;
- small contextual accent icon/shape di sekitar hook atau answer bila membantu comprehension;
- large flat editorial illustration dengan academic/student/document context;
- clean vector-like forms dengan soft rounded treatment;
- restrained navy/gold/cream supporting objects;
- compact service cue/footer strip bila series membutuhkannya;
- generous whitespace di antara text blocks;
- stable visual rhythm dan strong center axis;
- subtle corner decoration (gold rounded shape/dots) hanya sebagai framing, bukan focal point.

### 3.2 Reference Composition Anatomy

Gunakan anatomi berikut sebagai default composition recipe. Ini adalah **relative layout guidance**, bukan pixel lock:

1. **Top framing / logo zone** — logo ditempatkan centered atau near-centered pada bagian atas, dengan ruang napas yang jelas dari tepi atas.
2. **Hook zone** — headline besar, bold, uppercase, maksimal beberapa baris, menjadi elemen pertama yang terbaca setelah logo.
3. **Answer zone** — rounded dark-navy panel yang lebar, berada tepat setelah hook; answer menggunakan warm gold dan menjadi second strongest hierarchy.
4. **Supporting copy zone** — satu blok singkat di bawah answer panel, dark navy/charcoal, centered dan mudah dipindai.
5. **Main illustration field** — menempati area visual terbesar pada bagian tengah-bawah. Ilustrasi harus langsung merepresentasikan konteks layanan yang sedang dijelaskan.
6. **Service cue strip** — bila digunakan, letakkan di bawah illustration field sebagai rangkuman visual kecil; gunakan icon + label singkat dan pisahkan item dengan divider tipis.
7. **Bottom framing** — label series/highlight atau CTA dapat ditempatkan di area bawah yang aman; gunakan framing dekoratif minimal.

Default visual reading order:

`LOGO → HOOK → ANSWER → SUPPORTING COPY → MAIN ILLUSTRATION → SERVICE CUE / CTA`

Jangan membiarkan illustration, decorative icon, atau footer mengalahkan hook dan answer.

### 3.3 Spatial Rhythm

Untuk menjaga kesamaan antar-Story, pertahankan prinsip berikut:

- Hook memiliki clear separation dari logo dan answer panel.
- Answer panel memiliki margin visual yang cukup dari hook dan supporting copy.
- Supporting copy tidak menempel ke illustration; berikan breathing room.
- Illustration field menjadi blok visual besar yang menyatukan halaman.
- Service cue/footer berada setelah illustration, bukan memotong focal illustration secara acak.
- Dekorasi sudut tidak boleh masuk ke text hierarchy atau membuat layout terasa penuh.
- Gunakan satu center axis untuk primary text dan primary illustration kecuali deviation telah disetujui.

### 3.4 Fixed vs Variable Elements

**Fixed / system-level:**

- canvas and aspect ratio;
- core palette relationship;
- canonical logo treatment;
- question → answer hierarchy;
- rounded answer-box concept;
- gold accent/divider language;
- overall composition anatomy;
- flat editorial illustration language;
- whitespace and spatial rhythm;
- applicable service/footer cue treatment.

**Variable / content-level:**

- question;
- answer;
- supporting copy;
- character;
- scene;
- document/object type;
- service icons;
- visual metaphor;
- contextual imagery;
- footer/CTA copy when required.

Do not redesign the core system merely to make individual Stories appear different.

Untuk workstream lain, baseline dapat diadopsi setelah explicit approval. Adopsi tidak berarti seluruh variable elements harus identik.

## 4. Reusable Layout System

Gunakan struktur visual yang konsisten untuk series yang saling berhubungan.

Default functional zones:

1. Logo zone — fixed.
2. Question / hook zone — dominant.
3. Answer zone — rounded navy panel with gold answer text.
4. Supporting copy zone — compact and centered.
5. Main visual field — large flat editorial illustration.
6. Service cue / footer / CTA zone — minimal and function-driven.

Satu consistent center axis digunakan untuk primary text pada baseline ini.

Variabel antar-Story:

- question;
- answer;
- supporting copy;
- character;
- scene;
- document/service objects;
- visual metaphor;
- service icons;
- CTA.

Jangan mengubah struktur inti hanya untuk membuat setiap Story terlihat berbeda.

## 5. Typography Standard

Typography hierarchy wajib konsisten dalam satu series:

- Logo: canonical asset, bukan generated text/logo.
- Question/hook: large, bold, uppercase atau title case sesuai approved source; first reading point.
- Answer: large, bold, warm gold, inside navy rounded panel; strongest message after question.
- Supporting copy: medium/regular, dark navy/charcoal, compact, centered.
- Service labels: smaller bold/semibold, short, legible at Story scale.
- CTA: visually distinct only when CTA exists.

Exact font family, font size, line height, dan tracking mengikuti approved Canva baseline untuk series terkait.

Jangan mengarang numeric typography specification dari screenshot/raster image. Jika angka diperlukan, ambil dari Canva source.

## 6. Color Standard

Palette harus mengikuti approved brand/reference baseline.

Core relationship:

- Background: warm cream/off-white.
- Primary: deep navy.
- Accent: warm gold/yellow.
- Secondary text: dark navy/charcoal.

Gold digunakan sebagai accent yang terkontrol: answer text, divider, icon accent, dan framing. Jangan mengubah gold menjadi dominant body color.

Warna baru boleh ditambahkan hanya jika diperlukan secara produksi dan tidak merusak brand hierarchy.

Jangan mengganti palette hanya demi novelty.

## 7. Illustration / Visual Asset Standard

Gunakan flat editorial illustration sebagai main visual language.

Preferred characteristics:

- academic/student/service context;
- believable educational or consultation scenario;
- visual metaphor langsung terkait dengan layanan Story;
- clean vector forms;
- rounded and friendly forms;
- consistent outline/treatment;
- navy/gold/cream as dominant relationship;
- restrained object density;
- clear focal subject;
- sufficient negative space untuk typography;
- illustration large enough to function as the main visual anchor.

Untuk Story layanan:

- **Editing:** prioritaskan visual dokumen/tulisan, proofreading marks, notebook, pen, laptop, atau aktivitas merapikan tulisan.
- **Document:** prioritaskan dokumen, layout halaman, citation/reference, laptop, paper stack, checklist, atau elemen formatting.
- **Review & Consultation:** prioritaskan review dokumen, discussion, feedback, annotation, atau consultation scene.
- **CTA:** illustration dapat diperkecil atau ditiadakan bila action clarity lebih penting.

Aset visual standalone preferred untuk placement manual ketika template Canva sudah dikunci.

Do not:

- place logo inside generated visual asset;
- generate replacement brand marks;
- add unnecessary slogans or claims into illustrations;
- add decorative UI/badges unless required by the content;
- use an illustration whose internal text introduces claims or service names not present in the canonical copy.

## 8. Decorative Asset Standard

Decorative elements harus berfungsi sebagai framing dan hierarchy support, bukan isi utama.

Allowed by default:

- small gold rounded corner shapes;
- small navy/gold dot grids;
- thin gold divider lines;
- simple circular service/support icons;
- small contextual accent shapes.

Rules:

- maksimal satu decorative treatment utama per corner/area;
- jangan menumpuk banyak sticker, badge, icon, dan abstract shapes;
- decorative elements tidak boleh mengganggu safe area atau readability;
- jika dekorasi tidak memberi fungsi framing/hierarchy, hapus.

## 9. Service Cue / Footer Standard

Untuk LAYANAN dan Story series yang menjelaskan beberapa layanan, service cue strip dapat digunakan sebagai secondary navigation.

Default treatment:

- icon sederhana dalam lingkaran navy;
- label singkat dalam dark navy;
- item disusun horizontal jika ruang memungkinkan;
- divider gold tipis antar-item;
- tidak boleh lebih dominan daripada main illustration atau answer.

Gunakan hanya service names yang berasal dari canonical service catalog/content state. Jangan membuat label baru hanya untuk mengisi ruang.

Footer label seperti `LAYANAN` boleh digunakan sebagai series marker bila telah disetujui oleh content state.

## 10. Safe Area Standard

Gunakan conservative working safe area:

- approximately 14% top;
- approximately 20% bottom;
- approximately 6% left/right.

Untuk 1080 × 1920 px, prinsip ini kira-kira berarti:

- top: ~269 px;
- bottom: ~384 px;
- sides: ~65 px.

Angka tersebut adalah working layout guidance, bukan klaim bahwa 1080 × 1420 px merupakan official Instagram safe-zone specification.

Exact pixel boundaries dapat dikunci lebih lanjut pada Canva source bila diperlukan oleh production baseline.

## 11. Copy Rules

- Gunakan copy sesingkat mungkin tanpa menghilangkan konteks yang dibutuhkan.
- Prioritaskan satu question, satu answer, supporting copy bila perlu, dan satu CTA bila relevan.
- Jangan menggunakan fixed word-count rule sebagai hard requirement.
- Jangan menambahkan copy baru hanya untuk mengisi ruang kosong.
- Jangan mengubah approved copy tanpa explicit revision.
- AI-generated visual text bukan bagian dari canonical copy dan harus dihapus/diganti bila muncul.

## 12. CTA Rules

CTA hanya digunakan jika tujuan content memerlukan action.

CTA treatment harus:

- jelas sebagai action;
- tetap di dalam safe area;
- tidak mengalahkan question/answer hierarchy;
- tidak menggunakan unsupported performance claim seperti “2× better”.

Untuk LAYANAN, CTA utama berada pada Story yang memang ditetapkan sebagai CTA story; jangan memaksa CTA ke setiap Story layanan.

## 13. Canva Production Rules

Canva adalah finalization layer.

Gunakan Canva untuk:

- typography;
- canonical logo placement;
- alignment;
- spacing;
- copy;
- CTA;
- service cue placement;
- final visual QC;
- export.

Jika template/baseline sudah approved:

- jangan mengganti layout dasar tanpa explicit decision;
- jangan mengubah logo secara otomatis;
- jangan menggunakan AI-generated logo sebagai replacement;
- gunakan copy/content dari canonical content document;
- gunakan generated illustration hanya sebagai visual asset, lalu audit seluruh internal text/marks sebelum finalisasi.

## 14. Production Workflow

`Brief → Analysis → Content/Visual Plan → Reference Lock → Asset Generation → Visual QC → Canva Finalization → Final QC → Export → State Sync`

Untuk series reusable:

`Approved Baseline → Story Prototype → QC → Replicate → Full-Series QC`

Reference Lock berarti menetapkan satu approved visual source/reference sebelum membuat Story berikutnya. Setelah reference lock, perubahan yang dilakukan harus berupa content-level variation yang tetap berada dalam composition grammar.

## 15. Visual QC Checklist

### Brand

- [ ] Canonical logo digunakan.
- [ ] Logo geometry/proportion tidak berubah.
- [ ] Palette sesuai approved baseline.
- [ ] Visual terasa sebagai BAKU Edit Tugas.

### Layout

- [ ] 9:16 / 1080 × 1920.
- [ ] Center axis dan alignment konsisten.
- [ ] Logo berada di top zone dengan breathing room.
- [ ] Question/hook berada pada first reading point.
- [ ] Answer berada dalam rounded navy panel dan memiliki dominant hierarchy.
- [ ] Supporting copy berada jelas di antara answer dan illustration.
- [ ] Main illustration menjadi visual anchor terbesar.
- [ ] Service cue/footer tidak mengalahkan main message.
- [ ] CTA hanya bila relevan.
- [ ] Core composition anatomy tetap terbaca.

### Visual

- [ ] Illustration/asset mengikuti approved flat editorial visual language.
- [ ] Visual langsung mendukung service/message.
- [ ] Illustration cukup besar dan tidak terasa seperti filler.
- [ ] Supporting objects restrained.
- [ ] Decorative elements berfungsi sebagai framing, bukan noise.
- [ ] Tidak ada generated logo/brand mark.
- [ ] Tidak ada internal illustration text yang tidak canonical.
- [ ] Negative space cukup.

### Safe Area

- [ ] Important content berada dalam conservative safe area.
- [ ] Logo aman dari top UI region.
- [ ] CTA/footer aman dari bottom UI region.

### Content

- [ ] Copy sesuai canonical content state.
- [ ] Service labels sesuai canonical service catalog.
- [ ] Tidak ada fabricated claim.
- [ ] Tidak ada fabricated statistics/social proof.
- [ ] Tidak ada unsupported absolute security/performance claim.

## 16. Approval Rules

### APPROVED

Gunakan hanya jika:

- visual system telah diperiksa;
- critical issues = 0;
- content sesuai canonical state;
- asset usage sesuai rules;
- Canva finalization selesai;
- final QC lulus.

### WORKING

Gunakan ketika desain sedang dikembangkan atau masih ada refinement yang diperlukan.

### DRAFT

Gunakan untuk eksplorasi yang belum disetujui.

### OPEN

Gunakan ketika keputusan produksi masih membutuhkan keputusan eksplisit.

### SUPERSEDED

Gunakan ketika baseline/decision sebelumnya digantikan oleh keputusan baru.

### BLOCKED

Gunakan ketika produksi tidak dapat dilanjutkan tanpa informasi atau asset yang wajib.

## 17. Non-Negotiable Rules

- No fabricated data.
- No fabricated sources.
- No fabricated testimonials/social proof.
- No unsupported performance claims.
- No unsupported absolute security/privacy claims.
- No AI-generated replacement logo.
- No unapproved text inside generated illustrations.
- Do not change approved copy without explicit revision.
- Do not change an approved visual baseline without explicit decision.
- Do not add complexity without a functional reason.

## 18. Current Canonical Reference

The current canonical visual reference for reusable BAKU Instagram Story production is the approved flat editorial Story system, with the latest LAYANAN reference composition serving as the practical service-poster composition reference.

The reference establishes:

- warm cream canvas;
- top-centered canonical logo placement;
- large navy hook;
- navy rounded answer panel with gold answer;
- compact supporting copy;
- large central service-relevant illustration;
- restrained corner decoration;
- optional service cue strip;
- minimal bottom series marker/CTA treatment.

The reference is authoritative for **composition language and visual relationships**, not for generated-logo usage or unsupported internal illustration text.

When exact numeric measurements are needed, the approved Canva source remains authoritative.

## 19. Reference Authority & Reuse

Use the following authority order for production decisions:

1. Explicit current project decision in `00_Context/DECISIONS.md`.
2. Approved Canva master/source for exact visual implementation.
3. This reusable production standard for system-level rules.
4. Approved exported PNG/reference artifacts for visual comparison and QC.

A raster reference must not be used to invent unsupported numeric specifications.

For reuse in a new Story Highlight workstream, inherit the system-level baseline first, then define and approve only the content-specific or series-specific deviations that are functionally required.

## 20. Change Control

Changes to this standard require explicit project decision and should be recorded in:

`00_Context/DECISIONS.md`

Changes to a specific Story series should be recorded in the relevant content directory rather than rewriting this standard.
