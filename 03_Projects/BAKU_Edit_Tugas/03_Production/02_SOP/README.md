# BAKU Edit Tugas — SOP

Directory ini berisi Standard Operating Procedures untuk menjalankan workflow produksi secara konsisten.

## Scope

- Intake & requirement analysis
- Risk and integrity authorization
- Academic production with AI
- Human review and edit boundary
- Academic compliance and source verification
- Originality and AI signal review
- Final QC, delivery, and archive

## Usage

SOP adalah prosedur operator. Terapkan SOP yang applicable berdasarkan approved Work Brief, service, risk, dan scope.

Jangan menerapkan kontrol yang tidak relevan hanya untuk menambah kompleksitas.
