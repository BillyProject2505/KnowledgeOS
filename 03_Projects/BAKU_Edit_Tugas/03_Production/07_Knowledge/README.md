# BAKU Production Knowledge Base

Knowledge used to support production work at BAKU Edit Tugas.

## Scope

This directory stores concise, reusable knowledge that improves editing and production decisions.

It is not intended to become a complete academic encyclopedia.

## Rules

- Prefer practical knowledge that is repeatedly useful in production.
- Keep claims traceable to authoritative sources when factual accuracy matters.
- Separate general guidance from client-specific requirements.
- Client instructions and institutional guidelines take precedence over baseline guidance when applicable.
- Do not store client personal data or confidential project documents here.

## Initial Topics

- Academic writing
- Research methodology
- Citation and referencing
- Document formatting
- AI-assisted academic work
