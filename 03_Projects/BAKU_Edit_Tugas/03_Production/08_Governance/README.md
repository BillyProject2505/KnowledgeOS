# BAKU Production Governance

Dokumen governance untuk menjaga keamanan data, integritas akademik, penggunaan AI, dan perubahan standar produksi BAKU.

## Scope

Governance berlaku untuk seluruh workflow produksi yang terdokumentasi di `03_Production/`.

## Core Principles

1. **Client data minimization** — simpan hanya data yang benar-benar diperlukan untuk pekerjaan.
2. **Confidentiality** — data dan dokumen klien tidak dimasukkan ke repository produksi kecuali ada alasan operasional yang sah dan kontrol yang sesuai.
3. **Human accountability** — AI membantu pekerjaan; manusia bertanggung jawab atas keputusan dan hasil final.
4. **Academic integrity** — layanan tidak boleh mengarang fakta, sumber, citation, data, atau hasil penelitian.
5. **Traceability** — perubahan terhadap workflow, SOP, standards, dan policy harus dapat ditelusuri melalui version control.
6. **Least privilege** — akses terhadap data klien dan sistem produksi dibatasi sesuai kebutuhan.
