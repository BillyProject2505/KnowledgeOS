# BAKU Edit Tugas — Templates

Directory ini berisi template operasional yang digunakan untuk membuat artefak produksi secara konsisten.

## Scope

- Requirement analysis
- Client intake
- Editing brief
- Production case
- Academic audit
- QC report

## Usage

Gunakan template sebagai titik awal, lalu sesuaikan hanya bagian yang memang diperlukan oleh case.

Template bukan pengganti Operating Model, SOP, Standards, atau QC rules.
