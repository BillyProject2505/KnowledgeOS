# BAKU Final QC Checklist

## Purpose

Final quality gate sebelum dokumen dinyatakan siap dikirim kepada klien.

## Status Gate

Dokumen hanya boleh berstatus `READY FOR DELIVERY` jika seluruh Critical Issue telah diselesaikan dan checklist wajib terpenuhi.

## 1. Requirement

- [ ] Semua instruksi klien telah diidentifikasi.
- [ ] Scope pekerjaan sesuai pesanan.
- [ ] Format, panjang, bahasa, dan deadline sesuai requirement.
- [ ] Instruksi khusus dosen/kampus/jurnal telah diperiksa jika tersedia.

## 2. Content

- [ ] Isi menjawab tujuan dokumen.
- [ ] Struktur logis dan lengkap.
- [ ] Tidak ada bagian wajib yang hilang.
- [ ] Makna dan intent penulis tetap terjaga untuk pekerjaan editing.
- [ ] Tidak ada klaim yang ditambahkan tanpa dasar yang jelas.

## 3. Language

- [ ] Grammar diperiksa.
- [ ] Spelling dan punctuation diperiksa.
- [ ] Bahasa konsisten.
- [ ] Istilah teknis digunakan secara konsisten.
- [ ] Academic tone sesuai konteks dan tidak dibuat berlebihan.

## 4. Coherence & Terminology

- [ ] Hubungan antarkalimat jelas.
- [ ] Hubungan antarparagraf logis.
- [ ] Tidak ada repetisi yang tidak perlu.
- [ ] Terminologi dan singkatan konsisten.
- [ ] Transisi tidak terasa dipaksakan atau generik.

## 5. Citation & Evidence

- [ ] Setiap citation yang dibutuhkan telah tersedia.
- [ ] Citation relevan dengan klaim yang didukung.
- [ ] Referensi dapat diverifikasi.
- [ ] Tidak ada sumber atau metadata bibliografis yang dibuat-buat.
- [ ] Citation style mengikuti requirement.
- [ ] Daftar pustaka konsisten dengan citation dalam teks.

## 6. AI Output

- [ ] Output AI telah melalui human review.
- [ ] Tidak ada hallucinated fact.
- [ ] Tidak ada hallucinated citation.
- [ ] Tidak ada perubahan makna yang tidak disengaja.
- [ ] Tidak ada placeholder, instruksi internal, atau AI artifact yang tertinggal.
- [ ] Bagian yang meragukan telah diverifikasi atau dihapus.

## 7. Formatting

- [ ] Heading dan hierarchy konsisten.
- [ ] Font, spacing, margin, indentation, dan numbering sesuai requirement.
- [ ] Tabel dan gambar terbaca serta memiliki penempatan yang benar.
- [ ] Page break dan pagination diperiksa.
- [ ] Header/footer diperiksa bila diperlukan.
- [ ] File dapat dibuka dan ditampilkan dengan benar.

## 8. Final Delivery

- [ ] Nama file benar dan profesional.
- [ ] Format file sesuai pesanan.
- [ ] Tidak ada file sementara atau versi yang salah.
- [ ] Dokumen final telah dibuka dan diperiksa sebagai file hasil ekspor.
- [ ] Semua Critical Issue = 0.
- [ ] Semua blocker delivery = 0.

## Issue Classification

### Critical Issue — harus diperbaiki

Contoh: fakta salah, citation palsu, perubahan makna, requirement utama tidak terpenuhi, bagian wajib hilang, atau file final rusak.

### Improvement — sebaiknya diperbaiki

Contoh: kalimat masih dapat diperjelas, transisi kurang halus, atau formatting minor yang tidak menghalangi penggunaan dokumen.

### Preference — opsional

Contoh: pilihan kata alternatif yang secara substansi sama dan tidak memengaruhi kualitas minimum yang disepakati.

## Final Decision

**READY FOR DELIVERY** hanya jika:

1. Critical Issue = 0.
2. Requirement utama terpenuhi.
3. AI output telah melalui human review.
4. Fakta dan citation yang relevan telah diverifikasi.
5. File final telah diperiksa setelah ekspor.
