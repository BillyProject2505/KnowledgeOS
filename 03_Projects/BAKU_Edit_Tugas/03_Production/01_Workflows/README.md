# BAKU Edit Tugas — Production Workflows

Directory ini berisi workflow normatif dan operational map untuk produksi BAKU Edit Tugas.

## Scope

- Operating Model
- Master Workflow
- Editing Workflow
- Control Matrix

## Usage

Workflow di sini adalah dasar routing pekerjaan dari intake sampai delivery. Jangan membuat workflow baru per layanan tanpa kebutuhan produksi yang terbukti.

## Related Standards

Service-to-production routing dirujuk dari:

- `../04_Standards/Service_Catalog_and_Workflow_Mapping.md`

Dokumen visual/content production menggunakan workflow yang relevan tanpa mengubah operating model normatif.

## Principle

Gunakan jalur produksi paling sederhana yang memenuhi requirement, control, risk, dan QC yang berlaku.
