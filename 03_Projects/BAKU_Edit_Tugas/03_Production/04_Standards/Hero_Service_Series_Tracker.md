## 1. Purpose

Track which Hero Service posters have been:

1. defined;
2. designed;
3. quality-checked;
4. finalized in Canva;
5. exported at production size;
6. published to Instagram.

The tracker separates **production completion** from **Instagram publishing completion** so a poster is not considered published merely because its design is finished.

## 3. Completion Gates

A Hero Service poster is considered **Production Complete** only when all production gates below are checked:

- [ ] Service identity confirmed against current catalog
- [ ] Content brief approved
- [ ] Visual concept approved
- [ ] Visual QC passed
- [ ] Canvas verified at **1080 × 1350 px**
- [ ] Aspect ratio verified at **4:5**
- [ ] Safe margin verified at **60 px**
- [ ] Major blocks use the approved rounded-rectangle system
- [ ] Approved visual system maintained
- [ ] Logo area reserved during generation
- [ ] Original logo asset inserted manually in Canva
- [ ] Copy, CTA, and service claims verified
- [ ] Final Canva QC passed
- [ ] Final export checked

## 4. Publishing Gate

A Hero Service poster is considered **Published** only when all of the following are recorded:

- [ ] Final production file exists
- [ ] Instagram post has been uploaded
- [ ] Published post URL is recorded
- [ ] Published creative matches the approved final version
- [ ] Caption is approved and published
- [ ] Publication date is recorded

## 5. Status Definitions

| Status | Meaning |
|---|---|
| ⬜ Not started | Work has not begun |
| 🟡 In progress | Work is actively being produced |
| 🟢 Production complete | Design passed final production QC |
| 🔵 Published | Poster is live on Instagram and publication is recorded |
| 🔴 Blocked | A critical issue prevents completion |

## 7. Update Rules

Update this tracker whenever a meaningful lifecycle state changes.

Minimum required update points:

1. Hero Service scope confirmed
2. Design started
3. Visual QC passed
4. Canva finalized
5. Final export verified
6. Instagram published
7. Post URL recorded

Keep status factual. Do not mark a stage complete without evidence.
