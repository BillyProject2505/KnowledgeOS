## 1. Purpose

This checklist verifies that every Hero Service poster is complete before Canva finalization and final export.

A poster is **not final** until all Critical items pass.

---

- [ ] Service name matches the approved service catalog.
- [ ] Service proposition is clearly distinct from other Hero Services.

## 3. Content Completeness

### Required message hierarchy

- [ ] Primary problem/hook is present where applicable.
- [ ] Main service headline is immediately understandable.
- [ ] Supporting statement explains the service clearly.
- [ ] Main benefits/features are present.
- [ ] Value proposition is present when included in the approved layout.
- [ ] CTA is present and actionable.
- [ ] Content follows **Problem → Solution → Benefit → CTA**.
- [ ] Copy is concise and free of unnecessary repetition.

### Proofreading / language

- [ ] Spelling is correct.
- [ ] Indonesian grammar is acceptable.
- [ ] Punctuation is correct.
- [ ] Capitalization is consistent.
- [ ] Service terminology is used consistently.
- [ ] No accidental AI-generated wording or malformed text remains.

---

## 4. Visual Completeness

- [ ] Master Frame visual DNA is recognizable.
- [ ] Hero-specific visual communicates the service.
- [ ] All major content blocks use rounded rectangles.
- [ ] Color palette remains navy / gold-yellow / cream / white.
- [ ] Typography hierarchy is clear.
- [ ] Font usage is consistent with the approved brand system.
- [ ] Icons are stylistically consistent.
- [ ] Decorative elements do not compete with the main message.
- [ ] Visual hierarchy is clear at Instagram feed scale.

---

## 5. Layout, Spacing & Alignment

- [ ] Canvas is **1080 × 1350 px**.
- [ ] Aspect ratio is **4:5**.
- [ ] Safe margin is **60 px on all sides**.
- [ ] No critical element crosses the safe margin.
- [ ] Left and right alignment is consistent.
- [ ] Repeated cards have consistent column widths.
- [ ] Comparable content uses aligned baselines.
- [ ] Vertical rhythm is balanced.
- [ ] Spacing between sections is intentional and consistent.
- [ ] No element is overcrowded or visually cramped.
- [ ] No unnecessary empty space has been introduced merely to fill the canvas.

---

## 6. Logo & Brand Asset Check

- [ ] Logo source asset is the approved original file.
- [ ] Logo is inserted manually during Canva finalization when exact fidelity is required.
- [ ] Logo colors are unchanged.
- [ ] Logo proportions are unchanged.
- [ ] Logo is not non-uniformly stretched.
- [ ] Logo does not overlap other critical content.
- [ ] Adequate logo clearance is maintained.

**Important:** AI-generated or redrawn logos do not pass this checklist.

---

## 7. CTA & Contact Check

- [ ] WhatsApp CTA is visually obvious.
- [ ] Approved WhatsApp number is exactly **0897-7706-838**.
- [ ] WhatsApp icon is used only where helpful and is not unnecessarily duplicated.
- [ ] When the WhatsApp icon is shown with the phone number, it sits immediately to the left of the number.
- [ ] CTA wording clearly tells the viewer what to do next.
- [ ] Instagram handle is not added to the bottom footer unless explicitly required by the poster brief.

---

## 8. Canva Finalization Check

- [ ] Final design has been reviewed in Canva at working scale.
- [ ] Manual logo placement is complete.
- [ ] Typography has been checked after Canva placement.
- [ ] Alignment and spacing have been checked after Canva placement.
- [ ] No accidental movement or distortion occurred during editing.
- [ ] Final Canva preview has been inspected at full-page scale.
- [ ] Final Canva preview has been inspected at feed/mobile viewing scale.

---

## 9. Technical Export Check

- [ ] Exported file is exactly **1080 × 1350 px**.
- [ ] Export maintains **4:5** ratio.
- [ ] No non-uniform stretching is present.
- [ ] Image quality is acceptable after export.
- [ ] Text remains readable after export.
- [ ] No element is unintentionally cropped.
- [ ] Safe margin is preserved in the exported file.
- [ ] Correct file type is used for publishing.

---

## 10. Conversion Check

- [ ] Viewer can understand the service within a few seconds.
- [ ] Primary benefit is obvious.
- [ ] CTA is easy to locate.
- [ ] Contact action is frictionless.
- [ ] Poster does not depend on the caption to explain its basic proposition.
- [ ] Poster has one clear primary communication objective.

---

## 11. Final QC Classification

### Critical issue — Must fix

Any failure involving:
- incorrect service identity;
- incorrect contact number;
- misleading claim;
- incorrect canvas/ratio;
- safe-margin violation;
- broken logo asset;
- unreadable or missing critical text;
- major layout/alignment failure.

### Improvement — Should fix

Examples:
- minor spacing imbalance;
- minor typography inconsistency;
- weak visual emphasis;
- small alignment deviations.

### Preference — Optional

Examples:
- minor decorative refinement;
- alternate icon choice that still follows the system;
- non-critical wording preference.

---

## 12. Final Sign-Off

A Hero Service poster may be marked **FINAL** only when:

- [ ] All Critical issues = 0
- [ ] Technical checks = PASS
- [ ] Brand checks = PASS
- [ ] Content checks = PASS
- [ ] Visual checks = PASS
- [ ] Conversion checks = PASS
- [ ] Canva finalization = PASS

**Final status:** `READY TO PUBLISH`
