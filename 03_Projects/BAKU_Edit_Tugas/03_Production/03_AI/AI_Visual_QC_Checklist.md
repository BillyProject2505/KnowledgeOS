# BAKU Edit Tugas — AI Visual QC Checklist

**Status:** Canonical QC Checklist  
**Version:** 1.0  
**Scope:** AI-generated visual assets before Canva finalization

## 1. Generation Boundary

- [ ] Output is a visual asset, not a complete poster.
- [ ] No BAKU logo was generated.
- [ ] No brand wordmark was generated.
- [ ] No readable headline/body copy is being used as final copy.
- [ ] No CTA or contact information was generated.
- [ ] No service badge, information card, or footer was generated.

## 2. Service Relevance

- [ ] Visual clearly represents the intended service.
- [ ] Visual metaphor is understandable for the target audience.
- [ ] No visual element creates a misleading service impression.
- [ ] No unsupported claim, statistic, testimonial, or promise is introduced.

## 3. Brand & Style

- [ ] Visual feels Professional + Modern + Academic + Approachable.
- [ ] Visual is compatible with the approved BAKU visual system.
- [ ] Style does not conflict with the Master Frame.
- [ ] Decorative elements are functional rather than arbitrary.

## 4. Composition

- [ ] Primary subject has a clear focal point.
- [ ] Composition leaves sufficient negative space for poster copy.
- [ ] Critical subject details are not placed where typography will be added.
- [ ] Asset can be integrated into the Master Frame without redesigning the system.

## 5. Technical / Generation Quality

- [ ] No obvious anatomy or object artifacts.
- [ ] No distorted or nonsensical objects.
- [ ] No accidental watermarks or unrelated marks.
- [ ] Resolution is sufficient for intended Canva placement.
- [ ] Cropping/framing is usable.

## 6. Decision

`ACCEPT` — asset can proceed to Canva.

`REGENERATE` — concept is correct but generation quality/boundary is not acceptable.

`REJECT` — asset is conceptually wrong, misleading, or incompatible with the approved system.

## 7. Canva Gate

AI Visual QC approval does **not** mean the poster is final.

After acceptance, continue to:

**Canva Composition → Final QC → Export**
