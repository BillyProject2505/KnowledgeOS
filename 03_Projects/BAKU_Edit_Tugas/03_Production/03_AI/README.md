# BAKU Edit Tugas — AI Production

Directory ini berisi aturan, workflow, dan QC untuk penggunaan AI dalam produksi BAKU Edit Tugas.

## Scope

### Academic / Editorial AI

- `AI_Workflow.md`
- `AI_Usage_Policy.md`
- `AI_QC_Checklist.md`

### Visual Production AI

- `AI_Visual_Production_Protocol.md` — canonical boundary dan workflow untuk image generation.
- `Hero_Service_Visual_Brief_Template.md` — input standard untuk Hero Service visual generation.
- `AI_Visual_QC_Checklist.md` — gate sebelum asset masuk Canva.

## Core Rule

> **AI generates the visual. Canva assembles the communication.**

AI digunakan sebagai production aid, bukan sebagai pengganti kontrol manusia.

AI tidak menjadi sumber kebenaran untuk:

- exact text;
- logo fidelity;
- exact pixel dimensions;
- production typography;
- precise spacing/alignment;
- final poster composition.

## Visual Generation Boundary

AI boleh menghasilkan visual asset seperti illustration, character, academic objects, environment, lighting, dan visual metaphor.

AI tidak boleh digunakan untuk menghasilkan sebagai final:

- logo atau wordmark BAKU;
- headline/body copy;
- CTA;
- WhatsApp/contact information;
- service badge;
- benefit cards;
- footer;
- typography;
- complete poster layout.

**Content Brief → Visual Brief → Image Generation → AI Visual QC → Canva Composition → Final QC → Export**

AI Visual QC approval is not final production approval.
