# BAKU Edit Tugas — AI Production

Directory ini berisi aturan, workflow, dan QC untuk penggunaan AI dalam produksi BAKU Edit Tugas.

## Scope

- AI workflow
- AI usage policy
- AI QC checklist

## Core Rule

AI digunakan sebagai production aid, bukan sebagai pengganti kontrol manusia.

AI tidak menjadi sumber kebenaran untuk:

- exact text;
- logo fidelity;
- exact pixel dimensions;
- production typography;
- precise spacing/alignment.
