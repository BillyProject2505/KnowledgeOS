# 30_Governance

## Purpose

This directory contains governance artifacts supporting the Meta AI-Native Production System's research, construction, decision, and controlled evolution process.

## Scope

Artifacts in this directory may define project-level governance mechanisms, decision controls, review boundaries, construction safeguards, and related governance records.

These artifacts do not automatically establish Universal-level governance authority.

## Authority Boundary

This directory is subordinate to the project-level framework defined in `../README.md`.

Individual governance artifacts remain authoritative only within their declared scope, status, and explicit authority boundary.

Repository placement does not itself create governance authority.
