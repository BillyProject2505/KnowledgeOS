# 1. Tujuan

Resource Recovery Package (RP-RS) merupakan paket pemulihan konteks yang digunakan untuk memulihkan seluruh sumber daya (resources) yang diperlukan agar ChatGPT dapat menggunakan aset, referensi, dan komponen pendukung secara konsisten selama proses kerja.

---

# 2. Ruang Lingkup

RP-RS mencakup seluruh sumber daya yang digunakan lintas proyek, antara lain:

- Asset Library
- Template Library
- Component Library
- Prompt Library
- Brand Assets
- Visual Assets
- Reference Assets
- Resource Registry

---

# 3. Kapan Menggunakan RP-RS

Gunakan paket ini ketika:

- RP-KN telah selesai dijalankan.
- RP-PD telah selesai dijalankan.
- RP-PJ telah selesai dijalankan (jika bekerja pada proyek tertentu).
- Memerlukan aset atau template resmi.
- Memulai proses desain, penulisan, atau produksi yang menggunakan resource bersama.

# 11. Expected Context

Setelah seluruh dokumen dalam RP-RS berhasil diunggah, ChatGPT diharapkan:

- Memahami lokasi dan fungsi seluruh resource utama.
- Menggunakan template dan aset resmi secara konsisten.
- Menghindari penggunaan resource yang tidak sesuai standar.
- Siap menggunakan resource lintas proyek dalam proses produksi.

---

# 12. Success Criteria

Recovery dianggap berhasil apabila:

- Seluruh dokumen Required (★★★★★) telah diunggah.
- Tidak ada resource wajib yang terlewat.
- Resource resmi dapat digunakan secara konsisten.
- ChatGPT mampu memilih dan menggunakan resource yang sesuai dengan standar repository.
