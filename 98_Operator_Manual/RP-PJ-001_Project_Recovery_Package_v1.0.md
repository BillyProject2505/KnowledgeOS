# 1. Tujuan

Project Recovery Package (RP-PJ) merupakan paket pemulihan konteks yang digunakan untuk memulihkan seluruh konteks proyek tertentu sehingga ChatGPT dapat melanjutkan pekerjaan pada proyek tersebut secara konsisten tanpa kehilangan tujuan, ruang lingkup, maupun keputusan yang telah ditetapkan.

---

# 2. Ruang Lingkup

RP-PJ mencakup seluruh dokumen yang bersifat spesifik terhadap suatu proyek, termasuk namun tidak terbatas pada:

- Project Charter
- Project Architecture
- Project Bible
- Project Standards
- Project Registry
- Project Decisions
- Project Workflow
- Project Roadmap

---

# 3. Kapan Menggunakan RP-PJ

Gunakan paket ini ketika:

- RP-KN telah selesai dijalankan.
- RP-PD telah selesai dijalankan.
- Memulai kembali pekerjaan pada suatu proyek.
- Berpindah dari satu proyek ke proyek lainnya.
- Melanjutkan proyek setelah jeda yang panjang.
- Memulihkan konteks proyek sebelum melanjutkan produksi.

# 11. Expected Context

Setelah seluruh dokumen dalam RP-PJ berhasil diunggah, ChatGPT diharapkan:

- Memahami tujuan dan ruang lingkup proyek.
- Memahami struktur repository proyek.
- Memahami seluruh keputusan, standar, dan artefak utama proyek.
- Mampu melanjutkan pekerjaan secara konsisten tanpa kehilangan konteks proyek.

---

# 12. Success Criteria

Recovery dianggap berhasil apabila:

- Seluruh dokumen Required (★★★★★) telah diunggah.
- Tidak ada dokumen wajib yang terlewat.
- Konteks proyek berhasil dipulihkan.
- ChatGPT mampu bekerja secara konsisten sesuai ruang lingkup dan standar proyek.
