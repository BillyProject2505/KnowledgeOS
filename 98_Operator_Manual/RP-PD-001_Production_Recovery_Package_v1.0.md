# 1. Tujuan

Production Recovery Package (RP-PD) merupakan paket pemulihan konteks yang digunakan untuk memulihkan seluruh konteks produksi sehingga ChatGPT dapat melanjutkan pekerjaan operasional sesuai standar repository.

---

# 2. Ruang Lingkup

RP-PD mencakup seluruh dokumen produksi yang mengatur workflow, standar produksi, quality assurance, style guide, production bible, serta dokumen operasional yang diperlukan selama proses produksi.

---

# 3. Kapan Menggunakan RP-PD

Gunakan paket ini ketika:

- RP-KN telah selesai dijalankan.
- Memulai pekerjaan produksi baru.
- Melanjutkan pekerjaan produksi yang terputus.
- Memerlukan konsistensi terhadap standar produksi.
- Sebelum membuat aset, dokumen, atau konten baru.
