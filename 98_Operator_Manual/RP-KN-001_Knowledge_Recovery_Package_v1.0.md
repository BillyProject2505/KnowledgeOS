# 1. Tujuan

Knowledge Recovery Package (RP-KN) merupakan paket pemulihan konteks yang digunakan untuk memulihkan seluruh pengetahuan dasar (Knowledge Foundation) sebelum melanjutkan pekerjaan lain. Paket ini menjadi fondasi bagi seluruh Recovery Package lainnya.

---

# 2. Ruang Lingkup

RP-KN mencakup dokumen-dokumen pengetahuan yang diperlukan agar ChatGPT memahami struktur, istilah, standar, tata kelola, dan hubungan antardokumen dalam ekosistem repository.

---

# 3. Kapan Menggunakan RP-KN

Gunakan paket ini ketika:

- Memulai percakapan baru.
- Konteks ChatGPT hilang atau tidak lengkap.
- Sebelum menggunakan Recovery Package lainnya.
- Sebelum membuat atau merevisi standar.
- Sebelum mengembangkan arsitektur repository.
